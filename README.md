# SAN GEORGE — Fine Jewelry & Gold

A responsive Arabic RTL storefront prototype inspired by the approved SAN GEORGE luxury jewelry reference.

## Included
- Black, antique-gold and warm-ivory responsive homepage
- Crowned interlocking SG-inspired monogram and SAN GEORGE wordmark
- Jewelry hero, five category tiles, gold-market banner, benefits and footer
- Interactive demo gold calculator with editable example rate (not live market pricing)
- Static HTML/CSS/JS; no framework build step required

## Preview locally
Open `index.html` in a modern browser.

## Publish free (optional)
GitHub Pages can host this static site: in repository Settings → Pages, choose `Deploy from a branch`, select `main` and `/ (root)`, then save. Publication is not enabled by this change.

## Notes
Jewelry photography is loaded from remote image URLs and requires internet access. Product checkout, inventory, live gold-market feed and production WhatsApp routing are not connected in this prototype.
